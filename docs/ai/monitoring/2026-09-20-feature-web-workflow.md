# Web workflow — Quan sát vận hành nháp

Ứng dụng local: theo dõi lỗi import, job metadata, ghép nhóm/hoàn tác, snapshot tải và lỗi từng item. Log quyết định gắn video ID, nguồn evidence và phiên bản; không xuất dữ liệu cá nhân ra dịch vụ bên ngoài mặc định. Chưa thêm telemetry hoặc dashboard vận hành; schema log/chính sách lưu sẽ chốt trong design.
